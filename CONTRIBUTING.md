# Contributing

Replications are welcome.

## Good contributions

- a run with another model
- a run with another provider
- a stronger retrieval method
- a human-reviewed ATT&CK mapping key
- a new sanitized test case with documented ground truth
- a statistical review
- a bug fix that does not silently change the experiment

## For a replication

Include:

- experiment number
- model ID
- provider
- run date
- dataset SHA-256
- treatment SHA-256, for Experiment 2
- ATT&CK release, for Experiment 3
- prompt changes
- result file
- short interpretation

Do not commit API keys or confidential telemetry.

If you change the experimental design, describe it as a new condition or version. Do not present it as an exact replication.
